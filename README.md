# Excelから乗り換えるDuckDB入門 サンプルコード

書籍『Excelから乗り換えるDuckDB入門 2.0対応 VLOOKUP・SUMIFS・ピボットテーブルの集計をSQLで』（早瀬 透）のサンプルコードです。

本では、みどり文具株式会社の月次売上報告を、1章に1作業ずつ DuckDB に移していきます。このリポジトリには、**サンプルの売上データ**（`data` フォルダー）と、**各章を終えた時点の SQL ファイル**（章ごとのフォルダー `ch02`〜`ch11`）が入っています。本文のコードの枠と、その章のフォルダーのファイルは同じ内容です。

サンプルの売上データ（売上・商品マスタの .xlsx と CSV）は架空のものです。
